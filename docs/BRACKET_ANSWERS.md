# Ответы в тексте задания

Отдельный раздел «Правильный ответ» удалён у всех типов заданий: в обычном редакторе, быстром редактировании, группах пунктов и компактных строках True/False. Скрытого старого поля, которое появлялось для `___`, больше нет.

| Задание | Пример ввода |
| --- | --- |
| Заполнить пропуск | `Ja [bývam/žijem] tu.` — обе формы допустимы |
| Выпадающий список | `Ja [bývam/bývaš] tu.` — первая форма правильная |
| Выбор вариантов | `[Bratislava]`, затем `Košice` с новой строки; каждый правильный вариант в отдельных скобках |
| True/False | `Slon je malý [false]` или `Strom je vysoký [true]` |
| Таблица | `Anna / [Bratislava] / [slovenčina]` |
| Карточки | `auto [машина]` |
| Словарь | `auto [машина]`; аудио и примеры также сохраняются |
| Соединить элементы | `auto [машина]`, затем следующая пара с новой строки |
| Распределить по колонкам | `Ovocie: [jablko/hruška/banán]`, затем `Zelenina: [mrkva/uhorka]` с новой строки |
| Найти ошибку | `Ja [bývať/bývam] tu.` — ошибочное слово и его исправление |
| Перетянуть слова | `[Ja bývam v Bratislave.]` — правильная исходная последовательность |
| Порядок предложений/элементов | `[Ráno vstávam.]`, затем `[Potom raňajkujem.]` с новой строки |
| Открытый ответ | `Kde bývaš? [Bývam v Bratislave.]` — приватный образец для учителя; проверка остаётся ручной |

Текстовые и медийные блоки, запись произношения и интерактивные изображения не требуют отдельного эталонного текстового ответа. Их существующие инструменты редактирования сохраняются.

Для колонок можно записать сразу несколько слов одной категории: `Категория: [слово/слово/слово]`. Каждое слово становится отдельной карточкой; несколько строк одной категории объединяются в одну колонку. Старые `jablko [Ovocie]` и `Ovocie: jablko` остаются допустимыми. Допускаются фразы, пробелы возле `/` и повторяющиеся слова. Если косая черта является частью самого слова, используйте `\/`, например `Expressions: [and\/or]`. Пустая группа `Ovocie: []` считается незавершённой; в одном задании поддерживается до 100 карточек. Новый формат также принимается импортом урока из текста.

Старые уроки не переписываются в базе. При открытии редактора существующие ответы преобразуются в скобки для показа в поле текста. Старые форматы `___` с отдельным сохранённым ответом, пары через `=`, карточки через `|` и настроенные варианты продолжают работать. Если у нового `___` или `[]` ответа нет, нужно вписать его в скобки — дополнительного поля больше нет.

Преобразование для проверки выполняется общей функцией `SlovaExerciseFormat.prepare`, используемой предпросмотром, проверкой готовности и сервером. В публичных данных ученика нет маркеров правильных вариантов, исправлений ошибок и образца открытого ответа. Карточки передают обе стороны, поскольку их нужно переворачивать; упражнения на пары передают варианты, но не исходное соответствие.

Редактирование одного пункта не стирает ответы остальных пунктов. Удаление скобок с правильного варианта также удаляет его статус правильного, вместо возврата старого ответа из скрытых настроек.
