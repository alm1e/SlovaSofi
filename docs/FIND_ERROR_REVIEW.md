# Поиск ошибок в целом тексте

В существующем типе «Найди ошибку в тексте» пишите ошибочное слово и его исправление в одних скобках:

```text
Ja [bývať/bývam] v Bratislave.
Ona [ma/má] knihu.
My [chodí/chodíme] do školy.
```

Первое слово видно ученику; второе служит ответом для проверки. Можно вводить много предложений, сохранять абзацы и отмечать несколько ошибок в одном предложении. Каждую намеренную ошибку нужно отметить скобками: это упражнение с ответами преподавателя, а не автоматическая проверка орфографии. Одинаковые слова в разных местах проверяются независимо.

Ученик нажимает на ошибочные слова в полном тексте. Найденная ошибка выделяется зелёным и создаёт отдельное поле исправления внизу. Нажатие на правильное слово выделяет его красным и записывает ошибочный выбор. Enter или кнопка «Проверить» проверяет только соответствующее поле. Правильный ответ в соседнем поле сохраняет своё состояние.

Выборы слов, неверные попытки, проверенные ответы и черновики восстанавливаются после загрузки урока. Исправление ошибочного ответа не стирает историю ошибок. Задание завершается после нахождения и исправления всех заданных ошибок; прежние неверные клики не блокируют завершение. Учитель видит исправления и число ошибок. Хранятся последние 100 событий и общие счётчики попыток по каждому слову.

Проверка реальных ответов выполняется в `student-lessons` действием `find-error-event`. Изменения схемы базы не требуются. Клиент и Edge Function должны поддерживать это действие одновременно. Старые ответы с одним исправлением преобразуются в частичный результат для текста с несколькими ошибками. Объединённые задания сохраняют результаты отдельно для каждого пункта.

Проверки: ядро проверки, события DOM, очередь сохранения клиента, редактор и обработчик API с тестовой базой. Работа на настоящем iPhone/Mac и опубликованном сайте этими тестами не проверялась.
