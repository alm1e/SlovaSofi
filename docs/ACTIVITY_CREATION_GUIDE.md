## ????????? ???????

2. Несколько допустимых ответов: [bývam/žijem]. Ученик не увидит эти слова заранее.
3. Для картинок выберите «Картинки с ответами», загрузите файл, напишите ответ и добавьте карточку. Набор слов можно включить или выключить ниже.

## True ??? False

1. В строке утверждения напишите фразу и [true] или [false] в конце.
2. Нажмите «Добавить утверждение» для следующей фразы.
3. Если нужен вариант «Не сказано», используйте [not-stated]; он включится автоматически.

## ????????? ???????

2. В тексте задания одна строка — один ряд таблицы; столбцы разделяйте /.
3. Известные данные оставляйте без скобок, а ответы ученика пишите в [ ]. Несколько допустимых ответов внутри ячейки: [Bratislava/BA].
