# Домашние задания со сроком сдачи

## Включение

После предыдущих миграций применить один раз `supabase/migrations/20261120_homework_deadlines.sql` в SQL Editor. Затем обновить серверную функцию:

```sh
supabase functions deploy student-lessons
```

После этого опубликовать файлы сайта, включая assets/js/homework.js, teacher.html и student.html. Последовательность: SQL → функция → сайт. Эта работа не обновляет рабочую базу автоматически.

## Учитель

В карточке класса нажать «Домашние задания». Окно показывает срок, учеников, состояния и количество работ, ожидающих проверки.

«Назначить домашнюю работу» предлагает уже назначенные классу уроки с непустым разделом домашней работы. Выбрать урок, дату и время, добавить пояснение. Для одной пары класс–урок используется одно задание; срок и пояснение можно изменить позднее.

«Открыть ответы» открывает существующий просмотр ответов выбранного ученика в домашнем разделе урока. «Проверить» позволяет оставить комментарий и отметить сданную работу проверенной. Старую сдачу нельзя отметить проверенной, если ученик изменил домашние ответы или пересдал работу: нужно обновить список.

Назначать и проверять могут учитель своего класса и администратор. Директор только просматривает домашние работы школьных классов; личные классы ему недоступны. Для архивного класса доступны прошлые задания и проверка уже сданных работ, но новое назначение скрыто.

## Ученик

В кабинете появляется блок «Домашние задания» со сроками, пояснениями и комментариями. «Открыть домашнюю работу» переводит сразу в домашний раздел конкретного урока и класса. После выполнения нажать «Отправить на проверку» в блоке над уроком. Перед отправкой сайт дожидается сохранения ответов.

Состояния: «Не начато» → «В работе» → «Сдано» → «Проверено». Сдача — явное действие ученика; она не означает, что все ответы правильные. Пустые и частичные работы не запрещены, поскольку задания могут состоять только из чтения или просмотра. Проверку выполняет учитель.

Изменение домашнего ответа после сдачи или проверки возвращает эффективное состояние в «В работе»; нужен повторный submit. Изменение обычного упражнения урока и служебных полей проверки не сбрасывает домашний статус. Комментарий предыдущей проверки сохраняется. Повтор той же отправки без изменения домашнего ответа не создаёт новую сдачу.

После срока показывается «Просрочено», но отправка остаётся доступной. Все сроки хранятся как timestamptz; форма вводится в часовом поясе браузера, а отображение включает местный пояс. Автоматическая блокировка урока, email-рассылки и оценка выполнения не добавлялись.

## Данные и защита

Ответы не дублируются: используются существующие student_lesson_progress. Новые таблицы хранят назначение, срок, статус и комментарий. При сдаче сохраняется отпечаток только домашних response-полей; хеш не содержит правильных ответов из шаблона. Проверка сравнивает эту подпись и точное время сдачи.

Студент получает только собственные состояния, без результатов одноклассников. Сменить статус или подделать комментарий прямым UPDATE нельзя: изменения проходят проверенные RPC. Класс и урок задания нельзя поменять редактированием срока. Назначение, сдача и проверка попадают в журнал действий.

Архивация не удаляет задания. Удаление назначения урока удаляет связанное домашнее задание и статусы через FK, как существующее удаление назначения удаляет связанный прогресс. Для завершённых классов следует использовать архив.

## Проверки

`node --test assets/js/*.test.js` проверяет HTML-экранирование, статусы, просрочку, RPC и неизменность класса при правке срока. tools/verify-school-scope.cjs применяет реальные миграции в изолированном PostgreSQL и проверяет назначения, сдачу, проверку, изменение ответов, повторную отправку, приватность и ограничения ролей. Браузерные сценарии в tests/browser/teacher-ui.js и student-ui.js проверяют полный путь на изолированных данных.

После развёртывания проверить реальными аккаунтами: назначение → вход учеником → домашний ответ → сохранение → сдача → просмотр ответа учителем → комментарий → «Проверено» → изменение домашнего ответа → «В работе». Проверить отдельно обычное упражнение: оно не должно сбрасывать проверку домашнего.
