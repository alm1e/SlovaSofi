# Сохранение ответов ученика

Изменения затрагивают только сайт; новая SQL-миграция или обновление Edge Functions не нужны. Публиковать student.html вместе с assets/js/student.js и assets/js/student-drafts.js.

- Во время ввода показывается «Сохраняем ответ…», после подтверждения сервера — «Ответы сохранены». Ошибка сохранения показывает кнопку повтора. При восстановлении связи незаписанные ответы открытого урока отправляются снова.
- До отправки текстовые ответы, выбор вариантов, перестановки и рейтинги карточек сохраняются локально под идентификаторами аккаунта, урока, версии, задания и вопроса. Это копия незаписанных ответов, а не офлайн-версия уроков.
- При повторном открытии урока ответы, уже совпадающие с сервером, удаляются из резервной копии. Остальные предлагается восстановить явно; они не перезаписывают данные другого устройства без выбора ученика.
- При изменении версии урока старые ответы нельзя вставить в новые задания, но их можно скачать текстовым файлом. Доступно явное удаление копии.
- Переключение языка и перерисовка урока используют свежий ввод из очереди. Боковое меню и переход к другому уроку дожидаются сохранения; при ошибке ученик остаётся в текущем уроке.
- Запоздалое подтверждение старого запроса не удаляет более новый локальный ответ. События проверки «Найди ошибку» не переигрываются автоматически: после сбоя повторно сохраняется только черновик ответа.
- При ограничении хранилища или переполнении браузер показывает предупреждение, что резервную копию создать не удалось. Незавершённые записи вызывают стандартное предупреждение браузера при закрытии вкладки; мобильная ОС не обязана показывать его при принудительном завершении.
- Копии изолированы по аккаунтам и удаляются при успешном выходе. Очистка данных браузера удалит копии. Незагруженные аудио и файлы не сохраняются этим механизмом: для их загрузки требуется соединение.

## Приёмка в браузере

1. Открыть назначенный урок; ввести ответ и дождаться «Ответы сохранены»; обновить страницу и проверить ответ.
2. В DevTools включить Offline, изменить текст или выбор. Дождаться ошибки сохранения. Нажать раздел в боковом меню: открытый урок и ответ должны остаться.
3. Включить Online: дождаться подтверждения сохранения. Обновить страницу: ответ должен быть на сервере.
4. Повторить Offline-ввод, обновить страницу, затем восстановить сеть и открыть урок. Выбрать «Восстановить ответы» и проверить серверное сохранение. Пока сеть отключена, загрузка урока с сервера недоступна.
5. При наличии локальной копии изменить урок под учителем. После загрузки новой версии под учеником доступна выгрузка копии, но не восстановление в изменённую версию.
6. Проверить другой аккаунт в том же браузере: чужие копии не отображаются.

Автоматические проверки: `node --test assets/js/*.test.js`. Они покрывают очереди, отказ сети, новый ввод во время старого запроса, восстановление после создания нового экземпляра страницы, версии уроков, ограничения хранилища, изоляцию аккаунтов и переходы по меню. Браузерная приёмка после публикации проводится отдельно.
