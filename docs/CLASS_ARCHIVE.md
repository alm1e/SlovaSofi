# Архив классов

Применить один раз `supabase/migrations/20261118_class_archive.sql` в SQL Editor, затем опубликовать обновлённые JS-файлы сайта. Edge Functions обновлять не требуется.

В разделе «Классы» доступны вкладки «Активные» и «Архив». Учитель может перемещать собственные классы, администратор — любые. Директор только просматривает доступные школьные классы и их архив; личные классы по-прежнему скрыты.

Архивация меняет только teacher_classes.archived_at. Строки классов остаются в полном наборе данных кабинета: ученики, назначения уроков, ответы и прогресс не удаляются. Сохранение других частей кабинета не перезаписывает отметку архива. Удаление класса заменено в карточке обратимым архивированием.

В обзоре учитываются активные классы и их ученики. Ученикам доступ к пройденным материалам сохраняется: архив не является отключением учётной записи, курса или расписания. Архивный класс можно открыть для просмотра прежних уроков. Новое приглашение ученика скрыто в карточке архивного класса.

Проверки: `node --test assets/js/*.test.js`; изолированные PostgreSQL-проверки `tools/verify-school-scope.cjs` также проверяют запрет архивирования директором/чужим учителем и сохранность строк при архивировании и восстановлении. Браузерный сценарий включён в tests/browser/teacher-ui.js.
