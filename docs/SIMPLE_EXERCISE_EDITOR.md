# Упрощённое создание заданий

Обновление: отдельные поля ответа теперь удалены у всех заданий. Актуальные правила, заменяющие упоминания таких полей ниже, находятся в [BRACKET_ANSWERS.md](BRACKET_ANSWERS.md).

В поле текста и рядом с ним теперь находятся короткие примеры вместо длинного описания синтаксиса. Подсказки подготовлены для пяти языков интерфейса.

## Пропуски

```text
Ja [bývam] v Bratislave.
```

Слово в скобках становится пропуском. `[bývam/žijem]` допускает обе формы ответа. Отдельное поле ответа скрывается, когда все ответы заданы в тексте. Если использовать старые `___` или `[]`, поле появляется снова; старые ответы остаются в данных.

В предпросмотре учителя и в уроке ученика пропуски изначально пустые. Учитель может нажать **Показать ответы**, чтобы временно увидеть правильные слова как подсказки. Ответы ученика это действие не заполняет и не сохраняет.

## Порядок слов и предложений

Для слов напишите предложение в правильной последовательности:

```text
Ja bývam v Bratislave.
```

Для порядка элементов и предложений пишите по одному элементу в строке, также в правильной последовательности:

```text
Ráno vstávam.
Potom raňajkujem.
Idem do školy.
```

Отдельное поле ответа здесь убрано. При редактировании и сохранении решения берутся из исходной последовательности. Предпросмотр показывает элементы в другом порядке; сервер также перемешивает их для нового прохождения ученика. Если случайное перемешивание вернуло исходный порядок, сервер сдвигает элементы. Сохранённый ученический ответ при возвращении в урок восстанавливается.

`každý_deň` связывает два слова в один перетаскиваемый элемент. Существующие расширенные допустимые последовательности по-прежнему проверяются сервером.

## Два способа выбора ответа

- **Кнопки с ответами**: отдельные варианты с радиокнопками или флажками; каждый вариант с новой строки. Обычное поле правильного ответа остаётся.
- **Пропуск со списком**: варианты находятся прямо внутри предложения. Например, `Ja [bývam/bývaš/býva] v Bratislave.` Первый вариант в каждой паре скобок является правильным. В уроке вместо скобок появляется выпадающий список, варианты перемешиваются. Допускается несколько списков в одном тексте. Отдельное поле ответа для этого формата не требуется.

Старый формат выпадающего списка с `___` в первой строке и вариантами ниже продолжает поддерживаться.

## Таблица

```text
Meno / Mesto / Jazyk
Anna / [Bratislava] / [slovenčina]
Peter / [Košice] / [angličtina]
```

`/` разделяет колонки, новая строка — строки таблицы. Содержимое скобок — правильный ответ для этой ячейки. Ответы ниже таблицы заполнять не нужно. Сочетание старых пустых ячеек и новых ответов в скобках также поддерживается.

## Карточки

```text
auto [машина]
dom [дом]
```

Новая строка создаёт новую карточку. Отдельное поле перевода убрано. Старые `auto | машина`, `auto: машина`, настроенные карточки и сохранённые переводы из отдельного поля продолжают читаться. Если перевод раньше хранился отдельно, редактор показывает его в тексте карточки.

Вместо длинной вертикальной ленты показывается одна карточка со счётчиком и кнопками **← / →**. Работают клавиши со стрелками, когда фокус находится в карточках, и горизонтальный свайп на сенсорном устройстве. Клавиши внутри карточек не переключают раздел урока. Переворот карточки, отметки «знаю / повторить» и фильтр повторения сохраняются.

## Исправления редактора

- Enter в однострочном поле не отправляет форму урока. В многострочном тексте Enter продолжает добавлять строку.
- Предупреждение о незавершённом задании обновляется при вводе текста.
- Ненужные поля ответов действительно скрываются стилями; поле для старых пропусков появляется при вводе `___` или `[]`.
