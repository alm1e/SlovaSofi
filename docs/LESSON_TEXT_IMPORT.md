# Создание урока из текста

В редакторе раздела нажмите **Создать из текста**. В окне можно получить промпт с актуальными названиями заданий для текущего языка интерфейса, скопировать его в выбранный ИИ и вставить ответ. Внешний ИИ не вызывается самим сайтом; ключи API не нужны. Текст можно написать вручную.

Нажмите **Проверить и посмотреть**. После успешной проверки кнопка **Добавить в текущий раздел** добавит блоки в конец открытого раздела, включая раздел домашней работы. Существующие задания сохранятся. Изменение исходного текста сбрасывает подтверждённый предпросмотр. Дальше работает обычное сохранение черновика и урока.

В окне есть полный рабочий пример. Английские имена ниже также поддерживаются. Названия из интерфейса сопоставляются с существующими типами; новые типы в базе не создаются.

| Имя в формате | Существующее задание | Содержимое |
| --- | --- | --- |
| Text | Заголовок и текст | Обычный текст; `\| tip` после заголовка превращает его в заметку |
| Vocabulary | Словарь урока | `слово — перевод` или `слово / перевод`; примеры в `< >`, в том числе многострочные |
| GapFill | Заполнить пропуски | `Ja [bývam/žijem] tu.` |
| DropDown | Выпадающие варианты | Одна строка — один пункт, один `[верный/неверный]` пропуск |
| DragWords | Пропуски с банком слов | Текст с `[ответами]`; `~лишнее, слово` добавляет слова в банк |
| MultipleChoice | Выбор вариантов | `?Вопрос`, затем варианты по одному в строке; `*` перед каждым правильным |
| TrueFalse | Правда или неправда | `утверждение / ответ`; после заголовка можно задать `\| Правда / Неправда / Не сказано` |
| Table | Заполнить таблицу | Колонки через `/`, строки с одинаковым количеством ячеек, пропуски `[ответ/вариант]` |
| Matching | Найти пары | `левое — правое` или `левое / правое` |
| Unscramble | Перетянуть слова / собрать предложение | Предложение в правильном порядке, `_` связывает слова в один токен, `<вопрос>` необязателен |
| SortSentences | Порядок предложений | Каждое предложение в новой строке, в правильном порядке |
| ColumnSort | Распределить по колонкам | Название группы, слова по одному в строке, пустая строка между группами |
| FlipCards | Флип-карточки | `вопрос <ответ>`, многострочный ответ тоже допустим |
| Writing | Открытый ответ | Текст и вопросы, начинающиеся с `?` |
| HiddenText | Сворачиваемая заметка | `=Название кнопки` в первой строке, дальше содержимое; ученику доступна |
| TeacherNote | Заметка учителя | Не передаётся в ответе API ученику |
| Note | Заметка | Видна ученику; цвет и доступность дальше меняются обычными настройками |
| Image, Audio, Video | Соответствующие медиа | Одна действительная ссылка HTTP(S) |

`+Описание` и `++Примечание` сохраняются отдельно, отображаются ученику и редактируются в разделе **Описание / Примечание**. У обычного текстового блока показывается и заголовок. Примеры словаря отображаются отдельно и не добавляются к переводу при сохранении слова в личный словарь.

```text
#Заполнить пропуски: Место жительства
+Вставьте подходящий глагол
++Допускаются оба варианта
Ja [bývam/žijem] v Bratislave.

#Table: Doplň tabuľku
Infinitív / Minulý čas
go / [went]
dream / [dreamt/dreamed]

#TeacherNote: Перед заданием
Повторить названия городов.
```

Старый формат таблицы с запятыми и заголовками после `|` тоже принимается, но в самих пустых ячейках должны быть ответы: `go, [went], [gone]`. Импорт не угадывает, какие непустые ячейки скрыть. Обычные `___` и `[]` остаются доступны в редакторе, а для импорта нужно заменить их на `[ответ]`, чтобы проверка имела правильное решение.

Лишние предложения `~` в SortSentences пока не поддерживаются: импорт выдаёт ошибку, а не теряет их. Лишние слова поддерживаются в DragWords. Неизвестные типы и параметры, незакрытые `< >`, незаданные ответы и некорректные таблицы блокируют добавление. Ошибки содержат номер строки заголовка блока. Строку содержимого, начинающуюся с `#`, экранируйте как `\#`.

Ограничения импорта: 200 000 символов, 100 блоков, 100 пунктов в блоке; ограничения отдельных полей согласованы с API. HTML не исполняется: предпросмотр использует существующие безопасные средства отображения.

## Публикация

Кроме статических файлов изменён `supabase/functions/student-lessons/index.ts`: в публичные настройки добавлены только описания, примечания и подписи TrueFalse. Ответы остаются приватными. Эту функцию нужно обновлять вместе с сайтом, чтобы ученики получали новые поля.

Проверки: `node --test assets/js/*.test.js`. Тесты включают импорт примеров на пяти языках интерфейса, ошибки формата, запрет добавления после изменения текста, загрузку и проверку заданий через настоящий обработчик API с тестовой БД, приватность заметок и ответов.
