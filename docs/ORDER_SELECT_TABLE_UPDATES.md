# Порядок, списки и таблицы

В каталоге создания остался один тип **Правильный порядок**, использующий `sentence-order`: он работает с отдельными словами, элементами и предложениями. Старый `order-items` продолжает открываться и проверяться в существующих уроках. Сохранённые уроки не удалялись и не мигрировали. Старые названия порядка предложений также принимаются импортом.

В предпросмотре выпадающего списка фиксированный `reverse()` заменён перемешиванием Фишера — Йетса. Правильным остаётся первый вариант исходной записи `[правильный/неправильный]`, а видимая позиция меняется. На ученической стороне перемешивание выполняет сервер.

Учительский и ученический кабинеты используют общий компонент `select-ui.js`. Системный `select` скрыт стилем `display:none`, сохраняя значение и события формы. Видимые кнопка и список создаются в HTML и используют переменные текущей темы. Список размещается поверх страницы, чтобы его не обрезали контейнеры предпросмотра или модальные окна. Поддерживаются клавиатура, сенсорный выбор, Escape, отключённые варианты, состояния ошибки и правильного ответа. Открытие и выбор не вызывают системное меню Safari. При смене размеров окна меню пересчитывает положение.

У таблицы есть поле **Названия столбцов через /**. Пример: `Meno / Mesto / Jazyk`. Старую первую строку с названиями можно оставить в тексте: если она заполнена и не содержит пропусков, она распознаётся как строка заголовков. При редактировании таких названий они переносятся в настройки, без дублирования строки. Таблица отображает заголовки через `thead` и `th`.

После проверки таблицы каждая ячейка получает отдельный результат: правильные подсвечиваются зелёным, неверные — красным. Полностью выполненным задание считается после правильного заполнения всех пропусков. Сервер возвращает и сохраняет только массив логических результатов `blankResults`, без эталонных ответов; подсветка восстанавливается при загрузке сохранённого результата.

Проверки: `node --test assets/js/*.test.js` — 127 тестов, включая старые задания, случайное положение правильного варианта, события общего списка, заголовки и серверную проверку отдельных ячеек с последующей загрузкой прогресса. Ручная проверка на физических Mac/iPhone не выполнялась.

Изменения локальные. При публикации нужны статические файлы, новый `assets/js/select-ui.js` и обновлённая функция `student-lessons` вместе с её импортируемыми модулями. Схема базы не менялась.
